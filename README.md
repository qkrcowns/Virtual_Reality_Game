# Virtual_Reality_Game
4학년2학기 게임가상현실

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | **미정**  |
| 장르 | 3D Action / Free-for-All Battle |
| 개발 엔진 | Unreal Engine 5.8.2 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Third Person |
| 예상 플레이 시간 | 1판 3~5분 (반복 플레이) |

### 한 줄 소개
> 무작위 전장을 위에서 내려다본 뒤, 10명의 전사 중 무작위 한 명에게 빙의해 최후의 1인이 되는 3인칭 난전 액션 게임

---

## 2. 게임 컨셉

3개의 전장 중 하나가 무작위로 선택되고, 그곳에는 서로 다른 직업을 가진 10명의 전사가 배치되어 있다. 플레이어는 약 10초 동안 전장을 위에서 내려다보며 지형과 전사들의 위치, 직업을 파악한다.

관전이 끝나면 영혼은 10명 중 무작위 한 명에게 빙의한다. 나머지 전사들은 서로를 적으로 인식하고 싸우는 난전(Free-for-All) 상태이며, 플레이어는 빙의한 전사로 살아남아 나머지 모두를 쓰러뜨려야 한다.

어떤 직업에 빙의할지, 어디서 시작할지 매 판 달라지기 때문에 플레이어는 관전 단계에서 얻은 정보를 바탕으로 싸움에 끼어들 타이밍과 대상을 판단해야 한다.

### 핵심 키워드

- **Observe** : 전장 관전 및 정보 파악
- **Possess** : 무작위 캐릭터 빙의
- **Combat** : 직업별 공격과 스킬을 활용한 근접·원거리 전투
- **Survive** : 난전 속에서 최후의 1인으로 생존

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 무작위로 선택된 전장을 위에서 관전하며 지형과 전사들의 위치·직업을 파악한다.
2. 관전 종료 후 무작위로 선택된 전사에게 빙의한다.
3. 빙의한 전사의 공격과 스킬을 활용해 다른 전사들과 싸운다.
4. 전사들끼리 싸우는 상황을 이용해 유리한 타이밍에 전투에 참여한다.
5. 빙의한 전사를 제외한 모든 전사가 쓰러지면 게임 클리어
6. 빙의한 전사가 쓰러지면 게임 오버

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
무작위 전장 선택
  ↓
전장 관전 (약 10초)
  ↓
무작위 전사에게 빙의
  ↓
적 탐색 및 교전
  ↓
공격 / 스킬 사용
  ↓
적 처치
  ↓
다음 적 탐색
  ↓
최후의 1인 → 승리 / 사망 → 패배
  ↓
재시작 (새로운 전장, 새로운 빙의 대상)
```

플레이어는 한 판 안에서 **탐색 → 교전 → 처치 → 이동**의 과정을 반복하며, 매 판 전장과 직업이 바뀌어 반복 플레이가 가능하다.

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 회전 |
| Left Click | 기본 공격 (연타 시 콤보) |
| Q | 스킬 1 |
| E | 스킬 2 |
| Space | 회피 (구르기) |
| Shift | 달리기 |
| Esc | 일시정지 |

※ 기본 공격과 스킬의 실제 동작은 빙의한 직업에 따라 달라진다.

## 6. 플레이어 기능

### 6.1 이동

플레이어는 3인칭 시점으로 전장을 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 마우스 시점 회전
- 달리기
- 회피 (짧은 무적 시간을 가진 구르기)

### 6.2 전장 관전

게임 시작 시 플레이어는 캐릭터 없이 전장을 위에서 내려다본다.

주요 기능:

- 약 10초간 Top-Down 카메라로 전장 전체를 확인
- 각 전사의 머리 위에 직업 아이콘 표시
- 화면에 남은 관전 시간 표시
- 관전 중에는 모든 전사가 대기 상태

### 6.3 빙의

관전이 끝나면 영혼이 10명 중 무작위 한 명에게 빙의한다.

주요 기능:

- 생존 중인 전사 중 무작위 1명 선택
- 관전 카메라에서 빙의 대상에게 카메라가 이동하는 빙의 연출
- 빙의 완료 시 조작권 획득, 모든 전사가 동시에 전투 시작
- 빙의한 직업 이름과 스킬 정보를 화면에 표시

### 6.4 공격

주요 기능:

- 기본 공격: 연타 시 최대 3타 콤보 (직업별로 근접 / 원거리)
- 스킬 2종: 직업별 고유 스킬, 스킬마다 쿨다운 존재
- 공격 모션 중 대상 방향으로 자동 보정

### 6.5 피격 및 사망

주요 기능:

- 체력(HP) 감소 및 화면 상단 체력바 표시
- 피격 시 짧은 경직
- 체력이 0이 되면 사망 → 게임 오버 화면

### 6.6 UI

- 체력바
- 스킬 쿨다운 표시
- 남은 적 수
- 승리 / 패배 결과 화면 및 재시작 버튼

## 7. 직업 (Class)

| 직업 | 공격 방식 | 기본 공격 | 스킬 1 (Q) | 스킬 2 (E) |
|---|---|---|---|---|
| 전사 | 근접 | 대검 3타 콤보 | 돌진 베기 | 회전 베기 (주변 범위) |
| 궁수 | 원거리 | 화살 발사 | 관통 화살 | 후방 도약 (거리 벌리기) |
| 마법사 | 원거리 / 범위 | 마력탄 발사 | 화염 폭발 (지정 범위) | 순간이동 |

- 전장의 10명은 3개 직업 중 무작위로 배정된다.
- 캐릭터 에셋: Fab의 Paragon 영웅 에셋 활용 예정

---

## 8. 적 AI

빙의하지 않은 전사들은 AI로 움직이며, 플레이어와 다른 AI를 구분하지 않고 서로를 적으로 인식한다.

주요 기능:

- 시야 및 피격 감지를 통한 적 인식
- 가장 가까운 적을 목표로 설정, 공격받으면 공격한 대상으로 목표 변경
- 공격 범위에 들어오면 약간의 반응 지연 후 공격
- 스킬 쿨다운에 따른 기본 공격 / 스킬 선택
- 대기 중 목표를 바라보며 좌우 이동 (근접: 주위를 돌기 / 원거리: 거리 유지)
- 한 대상을 동시에 공격하는 인원 제한 (몰림 방지)
- 피격 시 경직, 사망 시 사망 모션 후 충돌 해제

## 9. 전장 (Map)

| 전장 | 특징 |
|---|---|
| 전장 1 | 개방형 평지, 정면 교전 위주 |
| 전장 2 | 기둥·벽 등 엄폐물이 많은 폐허 |
| 전장 3 | 높낮이 차이가 있는 계단형 지형 |

- 게임 시작 시 3개 전장 중 하나가 무작위로 선택된다.
- 모든 전장은 관전 카메라 한 화면에 들어오는 크기의 아레나 형태로 제작한다.
- 전장마다 10개의 스폰 지점을 배치한다.
- 환경 에셋: Fab 에셋 활용 예정
