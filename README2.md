# Virtual_Reality_Game
4학년2학기 게임가상현실

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임 제목 | 미정 |
| 장르 | 3D Action / Souls-like |
| 개발 엔진 | Unreal Engine 5.8 |
| 플랫폼 | PC |
| 플레이 방식 | Single Player |
| 시점 | Third Person (스테이지 시작 시 전경 카메라) |
| 예상 플레이 시간 | 20~30분 (튜토리얼 + 스테이지 2개) |

### 한 줄 소개
> 쓰러뜨린 적의 잔재를 흡수해 그 적으로 변신하고, 최대 3개의 폼을 바꿔 가며 보스에게 도전하는 3인칭 소울류 액션 게임

---

## 2. 게임 컨셉

플레이어는 쓰러뜨린 적의 잔재를 흡수하여 그 적의 몸과 능력을 그대로 얻을 수 있다.

흡수한 폼은 각자 별도의 체력과 고유한 특수 능력을 가진다. 전투 중 폼의 전환이 가능하다. 한 폼이 쓰러지면 남은 다른 폼으로 즉시 넘어간다.

스테이지 끝에는 흡수할 수 없는 보스가 있다. 플레이어는 진행하며 모은 폼과 아껴 둔 특수 능력을 조합해 보스를 쓰러뜨려야 한다.

### 핵심 키워드

- **Observe** : 전경 카메라로 스테이지 구조 파악
- **Absorb** : 쓰러뜨린 적의 잔재를 흡수해 새로운 폼 획득
- **Switch** : 3개의 폼을 상황에 맞게 전환, 전환 무적을 이용한 회피
- **Conquer** : 모은 폼과 특수 능력으로 보스 처치

---

## 3. 게임 목표

플레이어의 최종 목표는 다음과 같다.

1. 스테이지 시작 시 전경 카메라로 맵 구조와 보스 위치를 파악한다.
2. 구역을 진행하며 적을 처치한다.
3. 비전투 상태에서 적의 잔재를 흡수해 새로운 폼을 얻는다.
4. 폼을 전환하며 체력과 특수 능력을 관리한다.
5. 보스 아레나에 진입해 보스를 처치하면 스테이지 클리어
6. 스테이지 1을 클리어하면 스테이지 2가 해금된다.
7. 3개의 폼이 모두 쓰러지면 게임 오버

---

## 4. Core Gameplay Loop

게임의 핵심 플레이 흐름은 다음과 같다.

```text
전경 카메라로 맵 파악 (약 10초)
  ↓
구역 진행 및 적 발견
  ↓
전투 (기본 공격 / 회피 / 스킬 / 폼 전환)
  ↓
적 처치 → 잔재 생성 (30초)
  ↓
비전투 상태에서 F로 흡수
  ↓
새 폼 획득 (새 체력 확보)
  ↓
다음 구역 이동
  ↓
보스 아레나 진입 → 보스 처치
  ↓
스테이지 클리어 → 다음 스테이지 해금
```

플레이어는 전투 → 처치 → 흡수 → 전진을 반복하며, 흡수가 곧 회복이 되는 구조 속에서 보스까지 나아간다.

## 5. 플레이어 조작

| 입력 | 기능 |
|---|---|
| W / A / S / D | 캐릭터 이동 |
| Mouse | 시점 좌우 회전 (상하 회전 없음) |
| Left Click | 기본 공격 |
| Right Click | 스킬 |
| Alt | 회피 (폼별 회피기) |
| Shift | 달리기 |
| Space | 점프 |
| R | 특수 능력 (흡수한 개체마다 1회) |

| F | 잔재 흡수 |
| Esc | 일시정지 |

## 6. 플레이어 기능

### 6.1 이동 및 카메라

플레이어는 3인칭 시점으로 맵을 자유롭게 이동할 수 있다.

주요 기능:

- 앞으로 / 뒤로 이동
- 좌 / 우 이동
- 달리기
- 점프
- 회피 (폼별 회피기)

카메라:

- 마우스로 시점을 좌우로만 회전한다.
- 카메라의 상하 각도는 고정되어 있으며, 마우스로 위아래를 조작하지 않는다.

### 6.2 전투

모든 폼은 기본 공격, 회피기, 스킬, 특수 능력으로 구성되며, 실제 동작은 폼마다 다르다. (용병은 스킬과 특수 능력이 없음)

| 기술 | 설명 |
|---|---|
| 기본 공격 | 근접, 원거리 등 일반 공격 1회 |
| 회피기 | 폼마다 다른 회피 동작 (구르기, 도약, 순간이동 등) |
| 스킬 | 쿨다운이 있는 폼 고유 스킬 |
| 특수 능력 | 흡수한 개체마다 1회만 사용 가능한 강력한 능력 |

#### 소프트 타겟팅

별도의 락온 없이, 공격 시 가까운 적을 자동으로 보정한다.

- 공격(기본 공격, 스킬)을 누르는 순간 캐릭터 정면 약 60도, 일정 거리 안에서 가장 가까운 적을 찾는다.
- 대상이 있으면 그 적을 향해 빠르게 몸을 돌린 뒤 공격한다.
- 대상이 없으면 카메라가 바라보는 방향으로 공격한다.
- 원거리 공격(화살, 마법)은 대상이 있으면 대상의 높이에 맞춰 날아간다. 카메라 상하 조작이 없으므로 높낮이 조준은 소프트 타겟팅이 담당한다.
- 적을 계속 고정하지 않으므로 마우스 시점 조작을 방해하지 않는다.

### 6.3 흡수

적을 처치하면 그 자리에 잔재가 30초 동안 남는다.

주요 기능:

- 비전투 상태(플레이어를 추적 중인 적이 없는 상태)에서만 흡수 가능
- 잔재 근처에서 F를 누르면 입자 효과와 함께 흡수
- 흡수한 폼의 최대 체력 = 해당 적 최대 체력의 70%
- 빈 슬롯이 있으면 자동으로 저장
- 슬롯이 가득 찼다면 게임이 일시정지되고, 교체할 슬롯을 선택하거나 흡수를 취소

### 6.4 폼 슬롯 및 전환

| 규칙 | 내용 |
|---|---|
| 슬롯 수 | 기본 폼(용병) 포함 최대 3개 |
| 폼별 체력 | 각 폼은 별도의 체력을 가짐 |
| 수동 전환 | 1 / 2 / 3 키로 자유롭게 전환, 쿨다운 1.5초 |
| 전환 무적 | 수동 전환 순간 약 0.3초간 무적 → 타이밍을 맞추면 공격을 피하는 기술로 활용 가능 |
| 폼 사망 | 해당 슬롯이 비고, 다음 폼으로 자동 전환 (1 → 2 → 3 → 1 순서, 빈 슬롯은 건너뜀) |
| 자동 전환 무적 | 자동 전환 직후 1초간 무적 |
| 용병 폼 | 다른 폼과 동일한 규칙 적용. 쓰러지면 슬롯이 비며, 이후 흡수로 채울 수 있음 |
| 게임 오버 | 3개의 슬롯이 모두 비면 게임 오버 |

### 6.5 피격 및 사망

주요 기능:

- 피격 시 현재 폼의 체력 감소 및 짧은 경직
- 폼의 체력이 0이 되면 해당 폼 소멸 후 자동 전환
- 모든 폼이 소멸하면 게임 오버 화면 → 스테이지 재시작

### 6.6 UI

- 폼 슬롯 3칸 (폼 아이콘, 폼별 체력바, 특수 능력 사용 여부)
- 스킬 쿨다운, 폼 전환 쿨다운 표시
- 잔재 근처에서 흡수 안내 (F) 및 잔재 남은 시간 표시
- 보스 아레나 진입 시 보스 체력바
- 클리어 / 게임 오버 결과 화면

## 7. 폼 (Form)

| 폼 | 공격 방식 | 스킬 | 특수 능력 (흡수 개체당 1회) | 역할 |
|---|---|---|---|---|
| 용병 (기본) | 근접 | 없음 | 없음 | 기본 폼 |
| 전사 | 근접 (중량) | 대검 3타 콤보 | 현재 폼 체력 30% 회복 | 유지 |
| 도적 | 근접 (빠름) | 돌진 관통 베기 | 은신 (6초, 공격 시 해제, 비전투 상태로 넘어가기 용도) | 회피 |
| 궁수 | 원거리 | 3연속 화살 | 원거리 저격: 대상 최대 체력의 30% 피해, 맞은 적은 플레이어를 추적 (보스에게는 감소된 피해) | 선제 |
| 마법사 | 원거리 / 범위 | 화염 폭발 | 빙결 폭발: 주변 적 3초 동결 | 제어 |

- 같은 종류의 폼을 여러 개 흡수하면 각 폼에서 특수 능력을 따로 사용할 수 있다. (예: 궁수 1, 궁수 2 → 각각 1회씩 저격 가능)

## 8. 적 및 보스

### 8.1 일반 적

- 용병을 제외한 4개 폼(전사, 도적, 궁수, 마법사)이 적으로 등장한다.
- 적마다 감지 범위가 있으며, 플레이어가 범위 안에 들어오면 감지하고 공격한다.
- 적은 이동, 기본 공격, 스킬을 사용하며 특수 능력은 사용하지 않는다.
- 공격 전 약간의 반응 지연, 스킬 쿨다운, 피격 경직을 적용한다.
- 처치 시 흡수 가능한 잔재를 남긴다.

### 8.2 보스

- 흡수(변신)할 수 없는 특수 보스
- 3개의 공격 패턴, 체력 50% 이하에서 2페이즈 돌입
- 보스 아레나 진입 시 입구가 닫히고 보스 체력바 표시

## 9. 스테이지 구성

### 9.1 스테이지 구조

각 스테이지는 하나의 레벨 안에서 구역을 진행한 뒤 마지막에 보스와 싸우는 구조다.

```text
시작 지점 → 구역 A → 구역 B → 구역 C → 보스 문 → 보스 아레나
```

| 레벨 | 내용 |
|---|---|
| 메인 메뉴 | 튜토리얼 / 스테이지 선택 |
| 튜토리얼 | 기본 조작과 핵심 시스템을 배우는 작은 맵 |
| 스테이지 1 | 기본 적 위주, 첫 번째 보스 |
| 스테이지 2 | 스테이지 1 클리어 시 해금, 더 강한 적 구성, 두 번째 보스 |

- 플레이어 시작 위치와 적 배치는 고정이다.
- 스테이지 시작 시 약 10초간 전경 카메라로 맵 전체와 보스 위치를 보여준다. (재도전 시 스킵 가능)
- 맵은 Fab 에셋을 활용해 제작하거나 완성된 맵을 활용한다.
- 해금 정보는 저장되어 게임을 다시 실행해도 유지된다.

### 9.2 튜토리얼

튜토리얼 맵에서는 플레이어의 체력을 매우 높게 설정하여 안전하게 시스템을 익힐 수 있도록 한다.

진행 방식:

- 특정 지점에 도달하면 게임이 일시정지되고 화면이 어두워진다.
- 설명해야 하는 대상(적, UI 등)을 밝게 강조하고 설명 글을 표시한다.
- 확인 버튼을 누르면 게임이 재개된다.

튜토리얼 내용:

1. 기본 이동, 점프, 기본 공격, 회피, 스킬
2. 소프트 타겟팅 (공격 시 가까운 적 방향으로 자동 보정)
3. 적의 감지 범위 (적 발밑의 연한 반투명 노란색 원으로 표시)
4. 적 처치 후 잔재 흡수 (F)
5. 폼 슬롯과 폼 전환 (1 / 2 / 3)
6. 특수 능력 사용 (R)
7. 전환 무적 회피 : 적의 공격 타이밍에 맞춰 폼을 전환하면 공격을 피할 수 있음
8. 폼 사망 시 자동 전환
